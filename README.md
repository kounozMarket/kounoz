# KONOUZ MARKET — storefront

Next.js (App Router, TypeScript, Tailwind CSS v4) customer-facing storefront.
Project docs live in `../docs/` — start with `../CLAUDE.md` and the latest `../docs/batches/` status file.

```bash
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

Environment: copy `.env.example` to `.env.local` and fill values when available.
